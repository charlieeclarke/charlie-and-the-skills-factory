Installer preview

zsh — install.sh 

    

    

      
      
    

  


  

    

      
npm / yarn

      
Skills are bundled in the package — nothing is fetched mid-install. Needs Node 14+.

      npx charlie-and-the-skills-factory
      yarn dlx charlie-and-the-skills-factory
    

    

      
Shell one-liner

      
No Node required. All seven keep their bare names — /spec, /tickets, /prototype and the rest.

      curl -fsSL https://raw.githubusercontent.com/charlieeclarke/charlie-and-the-skills-factory/main/install.sh | sh
    

    

      
Claude Code plugin

      
Managed through /plugin. All seven, namespaced — /skills-factory:spec.

      /plugin marketplace add charlieeclarke/charlie-and-the-skills-factory
/plugin install skills-factory@charlie-and-the-skills-factory
    

  


  
A skill of the same name is never overwritten blind — it is moved to ~/.claude/skills/.factory-backup/ with a timestamp first.
